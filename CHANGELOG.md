# Changes

## 0.1.0-beta.1 — Beta

- Switch between **Wireframe** and **Mockup** styles directly in the toolbar.
- Explore four editable examples: Landing, Desktop contact, Phone contact and Tablet order.
- Keep multi-control moves intact through release and cancellation, with reliable Undo/Redo.
- Download a drag-to-Applications Mac DMG and a portable Windows EXE; the Windows beta is untested.

## 0.1.0 — Development history

- Keep bold Rectangle captions in exported images and PDFs, with one searchable PDF caption.
- Include caption font files in standalone SVG exports.
- Keep source and license links usable in review packages and installer notices.

- Return from a component source to its library by double-clicking empty canvas space.

- Respond to quick slider clicks and keep following keys and text with the clicked field.

- Keep keyboard focus on the selected Trash card while scrolling through retained items.
- Show save errors clearly during close review and let you return to unsaved work.
- Keep the preview open when Escape closes its page picker in More Controls.
- Start with neutral control labels, refined sketch outlines and updated small icons.

- Find controls under consistent library names and alphabetical order, while keeping older Quick Add search terms.
- Use a narrower 920-point editing window.

- Create local wireframes using 86 controls in sketch or clean styles.
- Edit, arrange, group and reuse controls with Undo and Redo.
- Turn Labels and Text Inputs into multiline controls with Command/Ctrl-Return or Option/Alt-Return, keeping separate Undo steps.
- Accept single-line canvas text with Tab and insert tabs while editing multiline text.
- Organize pages, alternate versions, notes and review comments.
- Resize the notes and alternate-version panes, with sizes remembered for each project.
- Format notes with styled text, colors, sizes and inline icons while keeping the original text editable.
- Keep notes spacing consistent across mixed text sizes, icon-only rows and trailing blank lines.
- Use consistent named palette colors and numbered shades in text, notes, comments and choice controls.
- Navigate component sources with arrow keys, extend selections with Shift, and expand or collapse libraries.
- Keep page and component selection ready for keyboard navigation after saving from the File menu.
- Import images, use offline icons and add project fonts.
- Use a compact toolbar with clear panel states and zoom controls.
- Access project and editing commands from desktop menus, with text selection and Undo kept in the active field.
- Present linked pages with optional navigation, link hints and a large pointer.
- Export PNG, SVG and linked multi-page PDF files.
- Save editable projects locally and recover interrupted sessions.
- Keep the window responsive while checking larger projects, with Cancel available.
- Review unsaved edits before responding to a native macOS quit request.

Platform availability and remaining limitations will be listed with the release. Built-in updates are not available yet.
