# Wireframe application icon

Original Wireframe artwork, licensed GPL-3.0-only with the application. The page frame, image placeholder and selection handles describe wireframing without text or borrowed branding.

`wireframe.svg` is the editable source; `wireframe-small.svg` simplifies it for crisp 16/32 pixel use. The PNGs supply the desktop window icon; `Wireframe.icns` supplies the macOS application icon. `Wireframe.ico` is compiled by root `build.rs` through `windows.rc` into ordinary Windows Cargo builds, for both debug and release. The resource is linked only to the Wireframe binary. A missing resource compiler or compilation failure stops a Windows build; MSVC needs its Windows SDK resource compiler, while GNU targets need the matching resource toolchain. macOS/Linux targets skip resource compilation.

Regenerate on macOS with `python3 scripts/generate-app-icon.py`. This uses the project's pinned Rust SVG renderer, Apple's `iconutil`, and ImageMagick only to assemble the Windows ICO. Install Rust and ImageMagick first. Generated assets are committed so ordinary app builds do not need the artwork-generation tools. The static Windows package verifier compares every embedded icon image against this committed ICO; actual Explorer appearance and DPI variants require separate Windows visual checks. The existing 16/32/64/128/256 images are unchanged; no new 48px artwork is implied.
