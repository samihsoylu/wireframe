# Original project pictograms

The Thin Plus is original geometric artwork by Wireframe contributors, under GPL-3.0-only. Its editable vector path and24×24 view box are in catalog.json. It is constructed from two perpendicular 2-unit-wide bars, forming a 20×20-unit cross; no third-party path was copied or modified. The regular style describes its weight. The category alias places it with other plus symbols.
