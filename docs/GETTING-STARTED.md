# Your first wireframe

1. Open Wireframe and create a project.
2. Find a control in the library or use **Quick Add**. Drag it onto the canvas.
3. Double-click a text-bearing control to edit it. Use the inspector to change its appearance and options.
4. Add pages in the navigator. Give each a useful name, such as Home, Contact or Order.
5. Save your project as a `.wireframe` file. Keep this file to continue editing later.

Use **Undo** and **Redo** to revisit changes. Group related controls to move them together, or make a reusable component when the same content appears on multiple pages.

Click a page's notes to edit them, then choose **Save** or press Command/Ctrl+Enter. **Cancel** or Escape discards the draft. Notes can contain `*bold*`, `_italic_`, `&underlined&`, `~struck through~` and `-muted-` text, plus `{color:red}colored text{color}`, `{size:20}larger text{size}` and inline icons such as `:star-solid:`. Bracketed links such as `[Website](https://example.com)` appear in blue. Clicking the notes opens their original text for editing, including in presentation mode.

Named text colors use the drawing palette, including variants such as `red2` through `red6` and `gray1` through `gray6` (`grey` works too). For an exact color, use a hex value such as `{color:#ff0000}red{color}`. Unrecognized color values display as black.

To try a flow, assign page destinations to controls and open presentation mode using the play button. Presentation settings let you show navigation, notes, link hints and a large pointer. Press Escape to return to editing.

To share your work, export PNG, SVG or PDF. A multi-page PDF can preserve clickable page links. Exports are for sharing; keep the `.wireframe` file as your editable original.

Projects are local files. Imported images and project fonts are stored with the project. Keep your own backups in addition to the app’s recovery copies.
