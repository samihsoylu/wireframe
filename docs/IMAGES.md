# Embedded images

Add an Image from the library, then use **Import image…** in its inspector. PNG, JPEG and GIF are recognized by their file signatures. Images are stored in the project; reopening does not need the original file. The source menu assigns an existing project image. **Remove image** returns that control to its placeholder and retains the asset for reuse.

Importing a different file with a matching filename or filename stem offers **Use new**, **Use existing**, **Keep both**, or **Cancel**. Use new replaces the shared asset data everywhere while retaining its identity. Keep both creates a distinct asset. Automatic control dimensions follow the image; explicit width/height remain fixed. Source assignment inside a component is local to that instance. Import, assignment, clearing and shared replacement participate in Undo/Redo. Import plus assignment is one product history entry.

## Editing several images

Selecting Images and Cover Flow controls together exposes a shared source menu, import, removal, relative rotation and Sketch filter. Source changes apply to every selected compatible control; removal keeps the embedded asset for reuse. Import captures the selected targets before opening the chooser and assigns one asset to all of them. Each accepted operation is one Undo step. Choosing the existing source leaves Redo intact.

Rotation preserves each Image’s visible center and transforms its crop; Cover Flow retains its frame. Mixed filter values display an indeterminate checkbox. Border is shared only when all selected controls are Images. Cropping remains an individual-control operation. Import-conflict Escape cancels without clearing selection or changing the document/history. Empty, duplicate, stale or incompatible targets fail without partial changes. Changes inside a component remain local to that instance.

## Crop and rotation

**Rotate 90°** turns the image counterclockwise around its visible center. Its crop turns with it. **Crop image** opens eight handles on the canvas; drag a handle to adjust an edge or drag inside the selection to move it. The first selection covers80% of each dimension. Apply crop or Enter commits one Undo step. Cancel crop or Escape leaves the document unchanged. Other editing controls are disabled during the preview.

**Remove crop** restores the full image size at the current visible top-left. Auto-size preserves that visible position. At90°/270° with a crop, Auto-size uses the full rotated natural dimensions as the visible size and retains the crop. Transforms never rewrite the stored image bytes. Component children can crop and rotate locally; Reset local changes restores inheritance. An explicit crop removal is distinct from inheriting a source crop. Existing projects without a crop override keep their previous inheritance.

## Image appearance

**Show border** draws a frame without changing position, dimensions or crop. Raster content is inset five units per side; small frames reduce padding to keep a positive interior. Clean style uses a thin dark-gray outline; sketch style uses a heavier black outline. A parent crop clips the original image frame rather than creating a new frame at its clipped edge.

**Sketch filter** converts color to gray and emphasizes contrast boundaries. It processes transparency as well as color, retaining the two-pixel transparent extent produced on each side. Filtering precedes rotation and scaling, leaves asset bytes unchanged, and remains visible in crop preview. The filter uses five temporary source rows instead of an additional full floating-point image.

The **Text** field adds centered rich text over an imported image or its placeholder, on an85% white background with a pale outline. Font size, bold, italic, underline and inline formatting use shared text rendering. Labels are unwrapped and clipped to the visible image frame. Border, filter and text can be overridden inside a component and reset to its source values. Property edits participate in Undo/Redo and save/reopen. Empty Images show a white style frame and inset cross without a synthetic caption. Invalid, trashed or removed artwork keeps an **Image unavailable** label in the project default font size, independently of the actual rich caption. The normal canvas, thumbnail and export pipeline shares this drawing.

## Storage and drawing

Asset stores an ID, display name, actual media type and bytes. It never stores an absolute source path. Import identifies encoded bytes independently of the name. Opaque PNG and the first opaque GIF frame become JPEG at quality92; transparent images use PNG. An unchanged transparent PNG or JPEG retains its input bytes. Images above2×1024×1024 pixels are resized with their aspect ratio preserved. JPEG encoding and resampling results can vary from other implementations.

Shared scene data contains positioned raster images. Canvas and thumbnails use a retained texture; SVG embeds a PNG data URL; PNG export renders the same scene. Transparency and ancestor crop clips are preserved. Repeated use of an asset shares decoded data within a scene. Automatic placeholders are77×79. Invalid embedded payloads render an Image unavailable placeholder rather than preventing the rest of the page from rendering.

Reads and decoding are bounded:32MiB encoded input,32768 maximum dimension,64×1024×1024 decoded pixels,256MiB decoder allocation, and128MiB decoded pixels per scene. Resource and serialized project limits are checked before an import transaction is accepted; a failed transaction restores document and allocator state. Existing project limits remain32MiB raw assets and64MiB encoded document. Images which exceed the scene budget also use the unavailable placeholder.

## Online image search — candidate implementation

Choose **Search images…** in the image inspector, or use the **Search images** tab in **Import from Web**. Only an explicit search sends the search terms to Wikimedia Commons; no project or image is uploaded. Results arrive in pages of eight, with bounded thumbnail previews. Select a result to fetch a full preview, review its creator/licence/source, optionally choose Sketch it, and Load. Cancel, changed search/address/project, and late responses cannot import an image. Downloads retain the existing image limits and atomic one-step history. Search has a20-second network deadline and1MiB response cap; thumbnails use two workers,8seconds/2MiB/2megapixels each.

Credits are embedded in the image asset and are available under **Image credit** in the inspector with a Copy action and source/usage-terms link. Project save/reopen, copy, replacement, Undo/Redo and library transfer preserve the appropriate asset credits; using an existing different image preserves that existing image's credits. Exports do not automatically print credits: include the copied credit according to the linked terms when sharing. Files saved by this candidate use document version16; earlier projects remain readable, while earlier app versions will reject new saves to protect credits.

Provider references: [Commons image metadata API](https://www.mediawiki.org/wiki/API:Imageinfo), [search API](https://www.mediawiki.org/wiki/API:Search), [client identification policy](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy), [reuse guidance](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia). Independent review, matching-state UI checks and final integrated build/package validation are still required. This source change does not replace the published beta or close image fidelity/platform gaps.


Credit-bearing control/library clipboards and current-format whole-page clipboards use `wireframe-nodes-v3:` so earlier app readers cannot silently discard credits. Current readers retain supported `v2` input, including migration of older page payloads. A global four-worker network budget survives cancelled/reopened dialogs; each job retains its slot until it exits. Local screenshot text extraction is connected through File and the image inspector; see [screenshot text](SCREENSHOT-TEXT.md). Independent correction review and native/package acceptance remain open.
