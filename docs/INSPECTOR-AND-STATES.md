# Typed inspector and choice states

The inspector reads catalog-effective values from canonical recursive nodes. Single and shared editors expose supported appearance fields, family-specific options, row selection/icons/links, image and arrow actions, and component section resets as documented below. Unsupported fields remain unavailable. Exact compact layout, complete control-by-control visual fidelity and the native cases explicitly listed below remain open; earlier basic-control checkpoints are historical evidence, not the current feature boundary.

Edits use typed validation and sparse storage. Reset removes a difference from the current project default, including its inherited font size. Unknown values are preserved. Position locks preserve geometry; supported appearance edits remain available. Nested editing uses sibling-scoped IDs in the current group. Continuous edits participate in existing transactions; discrete state changes and resets can be undone/redone. Auto-size restores the catalog's applicable automatic dimensions and preflights layout; unsupported layout restores the prior dimensions.

Checkboxes and radio buttons support Normal, Selected, Disabled, Selected and disabled, Indeterminate, and Indeterminate and disabled. Default symbol and label ink follows the style: black in sketch and dark gray in clean. Explicit control colors survive style changes. Disabled ink is applied to the mark, outline, label and default inline-link color. Explicit rich-text color tags retain their formatting behavior. Choice labels start 20 units after the control origin; checkbox/radio symbols are 16/13 units. Requested state does not change automatic geometry. The shared renderer uses the existing licensed outline icons and an original rounded radio-minus bar. Optical checkbox bounds are14×14 inside a16-unit icon box. Half-unit placement rounds toward the positive axis, including symbols taller than their row. Typography and small raster edge differences remain acceptance work.

New checkbox/radio insertion creates a catalog node with automatic dimensions and inherited properties, instead of an initial fixed prototype rectangle. Older saved projects preserve their explicit geometry. New state edits clear legacy checked flags, and an explicit disabled-selected state is correctly projected as selected. Insertion uses the shared catalog path and each control’s supported defaults; older saved explicit geometry is preserved. See [catalog and layout](CATALOG-AND-LAYOUT.md).

Native macOS checks: insert a checkbox; select mixed disabled; undo/redo; Reset and undo reset; save; close/reopen; verify persisted state; select disabled-selected and verify menu dismissal; undo to the saved state. The saved file retains automatic dimensions and one explicit state property. Historical geometry at that checkpoint was 73.6875×25. The subsequent line-box correction produces 74×23 at 13 points; exact glyph widths remain an acceptance item.

Five property/state tests cover sparse legacy transitions, unknown-field retention, storage round trips, undo/reset, nested contexts, locks, invalid states, project-font inheritance, auto-size undo/rollback, all twelve checkbox/radio state combinations, symbol dimensions and disabled link colors. ## Shared row selection

Selecting compatible row-based controls exposes one Selection menu. Labels combine by row index in click order; a missing row is shown as `-`. The first selected control supplies the collapsed value and highlighted menu choice, including mixed values. None is available only when every control permits it; dropdowns require a row. Choosing an index updates only controls containing that index. The unchanged value is skipped so a no-op retains Redo. Reset removes explicit row values or local component overrides atomically.

Lists honor Header Row; dropdowns retain an empty first title while excluding subsequent blank lines. Tables omit the header and final column-size row, remove first-row sorting suffixes, decode escaped commas, join cells with comma-space and omit wholly empty row labels. This preserves the indexed behavior even when an omitted blank row means the highlighted canvas row differs from the menu's label. Table choice captions use display-text parsing; for example `[x]` appears as `x`. Single tables use the same named choices.
