# Adding controls from the library

Drag a control onto the canvas to see it before releasing. A drag starts after movement exceeds six screen points; holding still does not start one, even after a long pause. The library uses compact 68×68 tiles, centered thumbnails in a 68×46 image area, and one-line labels with ellipses where needed. Hovering shows the full name.

The point you grab stays attached to the floating control. Grab offsets include the padding around a fitted thumbnail. The floating preview uses full-size project artwork and retains its screen size across canvas zoom levels; placement converts its origin through the current zoom and pan. At the top or left canvas edge, the insertion origin is kept inside the viewport. The tile stays highlighted while held.

Release over the canvas to insert and select the control. Undo removes that insertion in one step. Escape, loss of app focus, or release outside the canvas cancels without editing the project. Double-click still inserts at the default position. The existing ability to begin a drag anywhere on a tile is retained.

The preview is transient: it never enters the document, undo history, recovery file or export. Release commits before canvas painting to avoid an empty frame between preview and placed control. The source press and grab offset are retained until release/cancellation, so a fast gesture still works when movement and release arrive together in the following frame. Motion before the press and after the release is excluded. A gesture that crosses the movement threshold and returns to its start remains a drag. Placement uses the release event position, even if subsequent hover motion arrives in the same frame.

Validation covers fitted-image geometry, padding grabs, clamped edge drops, real egui events across frames, preview paint bounds following the pointer at 50/100/200% zoom, panning, cancellation, coalesced/split-frame drags, long stationary holds followed by movement, returned excursions, release followed by hover motion, and one-step history. Native macOS checks cover final placement and Undo/Redo. A held native preview recording, exact onset timing, display-pixel alignment, library autoscroll and native Windows/Linux testing remain outstanding.
