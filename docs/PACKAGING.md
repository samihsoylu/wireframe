# Native packaging

Run `python3 scripts/package.py` to build a release archive, or add `--debug` for a development archive. The script resolves Cargo’s target directory through its metadata, including `CARGO_TARGET_DIR`. Packages contain the executable, original product source and build scripts, assets, documentation, GPL-3.0-only license and dependency notices. The source directory also includes the documentation and notices required to rerun the packaging script. Generate notices first with `python3 scripts/generate_notices.py` when needed. For Windows cross-compilation, pass `--target x86_64-pc-windows-gnu` with the Rust target and MinGW cross-linker installed. The script also accepts `x86_64-pc-windows-msvc` and `aarch64-pc-windows-msvc`, which require their own working toolchains. Pass the target explicitly instead of using `CARGO_BUILD_TARGET`. Native builds remain the default. ZIP entries with timestamps outside its supported range are clamped during archiving; their contents are preserved.
