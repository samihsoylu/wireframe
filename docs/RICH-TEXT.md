# Rich text and structured text

The parser retains source text and derives styled spans, hard/soft line breaks and optional bullets. It supports bold, italic, underline, strikethrough, disabled text, color/size tags and links. Escaped punctuation and unmatched syntax remain literal. Parsing has bounded work and nesting depth; remaining text is retained literally when a limit is reached.

The font-backed measurer produces positioned glyphs and per-line link rectangles. The shared scene freezes these positions for canvas, thumbnails and SVG/PNG export. Each canvas uses its own font atlas, avoiding accidental reuse of measurement-context texture coordinates. Zoom scales positions without changing wrapping. Real regular, bold, italic and bold-italic Comic Neue faces are bundled unchanged with OFL notices and pinned provenance in assets/fonts/comic-neue/. SVG embeds these fonts and the license; PNG uses the same font files. This establishes consistent local drawing, not final typography or complete Unicode shaping.

Shared rich rendering covers label, heading, link, paragraph, text area, button, text input, dropdown, search, checkbox and radio controls. Tables use structured cells. Other control families retain the initial renderer. The scene includes ancestor/control/cell clips, inline colors and sizes, underline/strike strokes, and links clipped to visible rows. Later controls remove covered link areas; surviving fragments become presentation hit regions and external SVG anchors. Presentation follows page: IDs and HTTP(S) links. SVG retains external links but does not invent destinations for other pages.

Grid parsing precedes inline formatting: comma/tab columns, escaped commas, empty cells, bare checkbox/radio tokens, first-row sort suffixes and an optional final weight/alignment row. With no positive weights, columns expand in proportion to intrinsic width. Otherwise zero-weight columns retain intrinsic width and positive weights divide the remainder. Missing alignment inherits the table setting; L/C/R overrides it.

Table layout uses rich-text metrics, per-column padding, body-row minimums and a natural header height. Increasing fixed frame height preserves existing rows and fills the remainder with alternating empty rows. Overflowing cell text is truncated to a fitting prefix before alignment; source text remains unchanged. The renderer draws selection/header fills, horizontal/vertical rules, clipped cells, fixed-size choices and sort arrows. Tree parsing exists; tree measurement and drawing remain unfinished.

Verification: eight parser/font tests plus seven shared-scene tests cover source retention, styled Unicode, clipped/wrapped links, overlapping control hit regions, inherited alignment, proportional column widths, stable rows, SVG font/license/link data, and actual PNG colors/dimensions. A canvas-input test follows an inline page link at 150% zoom. The full suite has 68 passing tests and warning-free Clippy. Native macOS inspection verified formatting, table choices/sorting, thumbnails and page navigation. The native PNG export is byte-identical to examples/render_text.rs output for the same fixture.

Remaining acceptance: final font/style matching, complete language/fallback behavior, hanging bullets, icon/macros, full color/theme names, control states, tables with scrollbars and specialized properties, clean-style font selection, additional family rendering, accessible text representation and large-document performance. The specimen table measures 169.78125×83; current metrics are recorded, not treated as final geometry. Windows/Linux runtime validation remains open.

Typed text/table properties and six-state choice rendering are integrated; see INSPECTOR-AND-STATES.md for the current field boundary and native evidence.
