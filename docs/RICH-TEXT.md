# Rich text and structured text

The parser retains source text and derives styled spans, hard/soft line breaks and optional bullets. It supports bold, italic, underline, strikethrough, disabled text, color/size tags and links. Escaped punctuation and unmatched syntax remain literal. Parsing has bounded work and nesting depth; remaining text is retained literally when a limit is reached.

The font-backed measurer produces positioned glyphs and per-line link rectangles. The shared scene freezes these positions for canvas, thumbnails and SVG/PNG export. Each canvas uses its own font atlas, avoiding accidental reuse of measurement-context texture coordinates. Zoom scales positions without changing wrapping. New projects embed four Wireframe Draft faces; older files without a font resource retain Comic Neue. Both families retain their OFL notices. Project fonts and positioned text are shared by the canvas and exports; see PROJECT-FONTS.md for coverage and portability limits.

Shared rich rendering covers label, heading, link, paragraph, text area, button, text input, dropdown, search, checkbox and radio controls. Tables use structured cells. Control-specific text and state rules are documented in their family specifications. The scene includes ancestor/control/cell clips, inline colors and sizes, underline/strike strokes, and links clipped to visible rows. Later controls remove covered link areas; surviving fragments become presentation hit regions and external SVG anchors. Presentation follows page: IDs and HTTP(S) links. SVG retains external links but does not invent destinations for other pages.

Grid parsing precedes inline formatting: comma/tab columns, escaped commas, empty cells, bare checkbox/radio tokens, first-row sort suffixes and an optional final weight/alignment row. With no positive weights, columns expand in proportion to intrinsic width. Otherwise zero-weight columns retain intrinsic width and positive weights divide the remainder. Missing alignment inherits the table setting; L/C/R overrides it.

Table layout uses rich-text metrics, per-column padding, body-row minimums and a natural header height. Increasing fixed frame height preserves existing rows and fills the remainder with alternating empty rows. Overflowing cell text is truncated to a fitting prefix before alignment; source text remains unchanged. The renderer draws selection/header fills, horizontal/vertical rules, clipped cells, fixed-size choices and sort arrows. Tree layout and drawing have a dedicated implementation; see TREES.md. Table scrollbar, specialized properties, irregular Sketch contours and broader native interaction acceptance remain open.

Labels and paragraphs use black (`#000000`) in Sketch style and dark gray (`#333333`) in Clean style unless a control color overrides the default. Standalone and inline links use `#085394` by default. Disabled controls use `#80808b`; explicit inline color markup retains its own semantics. Color changes do not alter text measurement, control geometry or saved source. Choosing an explicit black override in Clean style preserves it through style changes, undo and save/reopen.

Verification covers parser/source retention, measurement, glyph positioning, rich colors, state colors, clipped/wrapped links, layout, storage and history. Palette regressions inspect actual raster pixels as well as shared scene colors. Native checks and integrated scenarios are recorded in SESSION-SPEC.md. These checks do not establish complete language/fallback coverage, arbitrary-font parity or Windows/Linux runtime acceptance.

Tables resolve default text and link contrast separately for each row. Opaque backgrounds below weighted RGB brightness 153 use white ink; gray 153 uses normal style ink (Clean #333333, Sketch black) and blue links. Header gray and selected light blue (#95bcf2) retain normal ink. Selection indexes body rows when a header is enabled and never colors empty filler rows. Rules follow style ink. Checkbox and radio symbols have transparent interiors and use the row ink. Explicit stored text/link colors and inline markup remain authoritative; explicitly setting the default text color keeps it fixed across later style/background changes. Derived automatic-color hints exist only in layout, not saved projects.

Tables use one-unit Clean rules and two-unit Sketch rules, with separators positioned inside their column boundary and the frame kept inside the control bounds. Clean horizontal rules occupy whole document pixels at unit export scale. Filled triangles distinguish ascending, descending and combined sort directions. Checkbox symbols are 16 units and radios 13; their alignment uses a 12-unit cell anchor, rounded local x positions and an extra two-unit right inset. Cell clipping remains in force. Sketch contours remain regular approximations.

Table geometry tests inspect actual PNG grid coverage, inside-frame boundaries, filled sort interiors and checkbox/radio sizes and alignment. Table palette tests cover header offsets, the strict contrast boundary, out-of-range selection, custom blue backgrounds, sort and choice ink, real PNG choice pixels, explicit-color history, disabled persisted values and round trips. The inspector does not expose table state or link-color fields. Native macOS table palette inspection and export comparison are scoped checks; they do not establish complete table geometry or cross-platform acceptance.

Typed text/table properties and six-state choice rendering are integrated; see INSPECTOR-AND-STATES.md for the current field boundary and native evidence.

Canvas line metrics are independent of the font's natural line height. Each row uses its largest requested font size, a common baseline at height/1.27, and 20% spacing before the following row. Empty rows use the base size; there is no trailing interline gap. Width is rounded upward and total height to the nearest integer. The original shaped galley remains unchanged; explicit row metrics drive measurement, glyph positioning and full-row link bounds. Tests cover small/large spans, empty/trailing rows, wrapping and Unicode link geometry. Native 13/24-point checkbox dimensions and multiline presentation links were checked after this change.
