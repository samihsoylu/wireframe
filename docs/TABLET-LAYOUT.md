# Tablet frames

Tablet has portrait/landscape orientation, proportional fit/stretch modes, a transparent screen option and an independent status bar. Newly inserted Tablets stretch; documents with no explicit mode use proportional fit. Automatic dimensions are 616×916 or 916×616. Manual dimensions remain fixed across property changes; Auto-size restores the orientation's natural dimensions.

The layout module produces frame, fill, status and detail geometry independently of artwork or fonts. Fit centers a proportional frame and scales its contents. Stretch keeps frame sections, home/camera details and status content at their normal size; opposing frame sections compress when there is insufficient space. Status items disappear at strict width/height boundaries, while nonpositive fills are omitted safely. Landscape places the home detail on the left. Continuous indexed rings form the body and square screen border around a real transparent opening, without antialiased tile seams. Style-specific contours retain straight edges and full-contrast borders. Landscape Stretch rotates the frame sections opposite to Fit; camera/home placement remains independent, with the home detail on the left. Sketch Fit uses separate camera/home artwork anchors.

The status label is “Tab”. The clock uses local time, without a leading hour zero; midnight and noon are 12:00 AM and 12:00 PM. A value is captured separately for each control when its content first renders. Size, device options, appearance or project font changes refresh that control's value. Moving it, renaming the project, editing another control or merely waiting does not. There is no repaint timer and no time stored in the project. Reopening a document captures new values. `Editor::with_clock` injects a deterministic source for verification and export tooling.

The library, inspector, canvas, thumbnails and exports use the shared renderer. Four typed fields are implemented; there is no model or background-pattern selector. Normal history, persistence, automatic sizing and local component overrides apply. `examples/render_tablets.rs` generates an eleven-Tablet gallery with a fixed 9:52 AM clock; opening its saved project in the app displays the current local time instead.

Nine focused tests cover geometry boundaries, rotation, auto/manual dimensions, Undo, serialization, local overrides, clock formatting/caching, transparent underlays, straight full-contrast borders, seams and finite tiny-size geometry. Automated checks and generated images do not establish native desktop acceptance or identical artwork. Native macOS checks cover library drag insertion, orientation/auto-size, fixed dimensions, transparency Undo/Redo, both gallery styles and restart/resave preservation. Native PNG/SVG exports match the shared renderer exactly with their captured clock values. Exact contours/glyphs, nested clipping, additional clock invalidation paths and Windows/Linux validation remain acceptance work.
