# Demo sources and licenses

`demo.wireframe` is an original Wireframe example by Wireframe contributors, distributed under [GPL-3.0-only](../LICENSE). Northstar Studio, the contact details and the order are fictional sample content.

The four pages contain 40 editable controls drawn procedurally by Wireframe. The project includes no imported images, screenshots, third-party product artwork or external resource files. All five presentation links stay inside the project. Addresses ending in `.example` and `example.com` are sample text.

The project embeds all four **Wireframe Draft 1.004** font faces, derived from Comic Neue and distributed under **SIL Open Font License 1.1**. The complete copyright, OFL and modification notice are stored in the project's font notices. The font files match the bundled files in [`assets/fonts/wireframe-draft`](../assets/fonts/wireframe-draft), which retains the [OFL](../assets/fonts/wireframe-draft/OFL.txt), [modifications](../assets/fonts/wireframe-draft/MODIFICATIONS.txt) and [derivation hashes](../assets/fonts/wireframe-draft/derivation.json).

The demo font remains under the OFL when redistributed. See the [asset policy](../docs/ASSET-LICENSING.md) and [third-party notices](../THIRD_PARTY_NOTICES.md) for application assets and export notices.
